# File naming

| Type | Pattern | Example |
|---|---|---|
| Unit operation | `UO-NN-shortname.md` | `UO-04-capture-aex.md` |
| Literature note | `AuthorYear-shortslug.md` | `Hull2021-ip-rp-oligo-purification.md` |
| Topic review | `REV-shortslug.md` | `REV-ion-pair-reagent-alternatives.md` |
| Decision record | `DR-NNN-shortslug.md` | `DR-001-purification-mode.md` |
| URS | `URS-<system>.md` | `URS-prep-chromatography-skid.md` |
| Register | `<thing>-register.csv` | `equipment-register.csv` |

Numbers are zero-padded and never reused, even after a file is deleted. Registers use
stable ID columns so that rows can be cited from prose.
