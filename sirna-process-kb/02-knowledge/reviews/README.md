# Topic reviews

A topic review synthesises several literature notes into a position on one question. Named
`REV-shortslug.md`.

A review should end with a **position**, not a summary. The point of a review is to say what
the project should do and on what evidence, so a review that lists what has been published
without concluding anything has not done its job.

## Structure

1. Question being answered.
2. Sources considered, with citation keys.
3. What the evidence supports.
4. What the evidence does not support, and where the gaps are.
5. Position and recommendation.
6. What would change the position.
