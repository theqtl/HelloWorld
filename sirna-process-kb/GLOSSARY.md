# Glossary

| Term | Meaning |
|---|---|
| AEX | Anion exchange chromatography |
| AppRNA | 5'-adenylylated RNA, the dead-end intermediate of ATP-dependent ligation |
| ASTM E2500 | Standard for risk-based verification of manufacturing systems |
| Blockmer | A short oligonucleotide block intended for joining. See the terminology table in `03-process/upstream/blockmer-prep.md`, since the word carries three distinct meanings |
| BoD | Basis of Design |
| CGE | Capillary gel electrophoresis |
| CPP | Critical process parameter |
| CQA | Critical quality attribute |
| DMT | Dimethoxytrityl, the acid-labile 5' protecting group |
| DMT-on | Purification strategy retaining the trityl group as a hydrophobic handle |
| GAMP 5 | Guidance for computerised system validation |
| GPP | General process parameter |
| HETP | Height equivalent to a theoretical plate, a column performance measure |
| ICH | International Council for Harmonisation |
| IP-RP | Ion-pair reverse phase chromatography |
| IPC | In-process control |
| KPP | Key process parameter, important but not critical |
| Longmer | An impurity longer than the target sequence |
| n-1 | An impurity one nucleotide shorter than the target, from a failed coupling |
| n+1 | An impurity one nucleotide longer than the target |
| PAT | Process analytical technology |
| PKM | Process knowledge management |
| PO | Phosphodiester, in this context the missing-sulfur impurity of a phosphorothioate |
| PPQ | Process performance qualification |
| PS | Phosphorothioate backbone linkage |
| QTPP | Quality target product profile |
| RTRT | Real-time release testing |
| Shortmer | An impurity shorter than the target sequence |
| Splint | An oligonucleotide that bridges two blocks to position them for ligation |
| TFF | Tangential flow filtration |
| UF/DF | Ultrafiltration and diafiltration |
| URS | User requirements specification |
| VPE | Variable pathlength ultraviolet spectroscopy, used for in-line concentration |
